# Contributing Guidelines

Thank you for considering contributing to **NetCheck**! Please follow these guidelines to make the process smooth:

## How to Contribute
1. **Fork the Repository** – Create your own copy of the repo.
2. **Create a Feature Branch** – `git checkout -b feature/your-feature-name`.
3. **Make Changes** – Keep code style consistent with the existing code (PEP8, premium UI).
4. **Write Tests** – Add or update tests for new functionality.
5. **Update Documentation** – Update `README.md` or relevant docs if you change behavior.
6. **Commit Messages** – Use clear, descriptive messages. Example: `Add support for exporting device logs as CSV`.
7. **Push & Open PR** – Push your branch and open a pull request on the main repository.

## Code Style
- Use **Black** formatting (`black .`).
- Follow **PEP8** guidelines.
- Keep UI components premium and consistent with existing design.

## Testing
- Run `pytest -q` locally. All tests must pass before submitting a PR.
